03

Date mask

const formatDate = (value: string) => {
  const digits = value.replace(/\D/g, '')
  return [
    digits.slice(0, 2),
    digits.slice(2, 4),
    digits.slice(4, 8),
  ].filter(Boolean).join(' / ')
}
04

Text enforcement

<Rifm

  }

/>
02 / WHY RIFM

One small job.
Done carefully.

↳

Cursor aware

Formatting never feels like fighting the input. Rifm tracks accepted characters and restores the natural cursor position.

◇

Input agnostic

Native inputs, your design system, or a third-party text field. Rifm only supplies value and onChange.

±

Format anything

Numbers, dates, phone numbers, card masks, casing rules, and domain-specific values all use the same small API.

03 / GET STARTED

From zero to
formatted.

Install Rifm, keep your value in state, and pass the returned props to any text input.

!

Use type="tel" or inputMode for numeric keyboards. Native type="number" does not support selection ranges.

useRifmReact + TypeScript
import { useState } from 'react'
import { useRifm } from 'rifm'

const format = (value: string) =>
  value.replace(/\D/g, '')

export function AccountNumber() {
  const [value, setValue] = useState('')

  const rifm = useRifm({
    value,
    onChange: setValue,
    format,
    accept: /\d/g,
  })

  return (
    <input
      {...rifm}
      inputMode="numeric"
      placeholder="Account number"
    />
  )
}
